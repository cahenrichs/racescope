# RaceScope Plan

Public V1 is the current execution target. The project documentation is separated by purpose so release scope, long-term direction, and technical decisions can evolve independently.

- [Product Vision](docs/vision.md): purpose, audiences, decision rules, and post-V1 direction.
- [V1 Plan](docs/v1-plan.md): committed scope, milestones, exclusions, and definition of done.
- [Architecture](docs/architecture.md): technical direction, API shape, testing strategy, and implementation rules.

The only planned V1 scope-revision gate is after Milestone 3. Public V1 scope freezes after that review until release.
